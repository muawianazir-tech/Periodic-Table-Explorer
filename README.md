# Periodic Table Explorer

Periodic Table Explorer is an Android app built with Kotlin that lets users explore chemical elements, view details, and manage favorites in a simple interactive interface.

## Features
- Browse the periodic table
- View element details
- Save favorite elements
- Simple login/register flow
- Dark/light theme support

## Tech Stack
- Android Studio
- Kotlin
- Gradle

## Getting Started
1. Open the project in Android Studio.
2. Sync Gradle files.
3. Run the app on an emulator or physical device.

## Project Structure
- app/src/main/java - application source code
- app/src/main/res - layouts, drawables, and resources
- app/build.gradle.kts - app-level Gradle configuration
